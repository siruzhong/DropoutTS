# Towards Robust Time Series Learning via Capacity-Centric Modulation

Official code for **Capacity-Centric Modulation (CCM)** and its instantiation
**Sample-Adaptive Capacity Modulation (SACM)** for robust time series learning.

> **Naming.** The repository and code keep the name **DropoutTS** from the
> ICML 2026 paper. The extended version presents the same mechanism as
> **SACM** under the **CCM** framework.

## Overview

Sample-level reliability heterogeneity is common in deep time series learning:
a uniform regularization setting under-regularizes corrupted samples and
over-restricts clean samples. Instead of filtering observations in data space or
imposing priors on latent representations, SACM assigns a **per-sample dropout
probability** to the trainable activation paths of an existing backbone, driven
by a spectral reliability score. It integrates into standard backbones without
architectural redesign, and the deterministic inference pipeline is preserved,
so there is **zero test-time overhead**.

### Key results

Across **301 real-world dataset–backbone pairs** (9 forecasting, 32
classification, and 4 anomaly-detection datasets):

| Task | Metric | Improvement |
| :--- | :--- | :--- |
| Forecasting | MSE (avg.) | **-6.7 %** |
| Classification | Accuracy (avg.) | **+3.04 %** |
| Anomaly detection | Point-adjusted F1 (avg.) | **+17.05 %** |

relative to the unmodified backbones.

## Repository structure

```
.
├── run_baselines.py                          # Forecasting baselines and SACM variants
├── run_classification.py                     # Classification (32 datasets)
├── run_anomaly_detection.py                  # Anomaly detection (SMD/MSL/SMAP/PSM)
├── src/basicts/
│   ├── modules/dropout_ts.py                 # Core: SampleAdaptiveDropout, NoiseScorer, DropoutTS
│   ├── runners/callback/dynamic_dropout.py   # DropoutTSCallback (training integration)
│   ├── models/                               # Backbones (PatchTST, iTransformer, TimeMixer, ...)
│   └── ...                                   # BasicTS framework (data, runners, metrics)
├── scripts/
│   ├── run_dt_sl.py                          # SACM for forecasting (+ Selective Learning)
│   ├── run_multiseed.py                      # Multi-seed runs + paired t-test
│   ├── run_dropout_strategy_comparison.py    # Fixed / global-learnable / SACM comparison
│   ├── run_pretrain_estimator.py             # Pretrain the DLinear estimator (Selective Learning)
│   ├── run_batch_size_sweep.py               # Batch-size sensitivity sweep
│   └── data_preparation/                     # Per-dataset preprocessing (run.sh)
├── vis/                                      # Figure scripts (spectral analysis, sensitivity, ...)
└── requirements.txt
```

The training framework, model zoo, data pipeline, and runner under
`src/basicts/` are derived from [BasicTS](https://github.com/GestaltCogTeam/BasicTS);
the SACM/DropoutTS module, the callbacks, and the experiment scripts are original
to this project.

## Installation

Requires Python 3.9+ and a CUDA-enabled PyTorch installation. Install PyTorch
for your CUDA version from [pytorch.org](https://pytorch.org/get-started/locally/),
then install the remaining dependencies:

```bash
pip install -r requirements.txt
```

Run every command below from the repository root. The scripts add `src/` (and
the repository root) to `sys.path` automatically, so no manual `PYTHONPATH`
setup is needed.

## Data preparation

Preprocessed data is expected under `datasets/` (git-ignored). Download the raw
files (ETT, Electricity, Weather, ExchangeRate, ILI, ECG, the UEA archive, etc.)
into `datasets/raw_data/<Name>/` and then run:

```bash
bash scripts/data_preparation/run.sh
```

Synthetic benchmarks (`SyntheticTS_noise{0.1..0.9}`) are generated by
`scripts/data_preparation/SyntheticTS/`.

## Usage

All entry scripts are self-contained experiment drivers: they import the models
and datasets directly and dispatch jobs across the GPUs listed in
`AVAILABLE_GPUS` (defaults to `[0, 1, 2, 3, 4, 5, 6, 7]` — edit this to match
your machine). Model and dataset grids are defined at the top of each script.

**Forecasting.** Baselines and SACM variants:

```bash
python run_baselines.py             # baselines + SACM across the forecasting model zoo
python scripts/run_dt_sl.py         # SACM (optionally combined with Selective Learning)
```

The default SACM configuration used in the paper is:

```python
p_min = 0.05
p_max = 0.50
init_alpha = 10.0
init_sensitivity = 1.0
sparsity_weight = 0.0
use_gate = False
```

**Classification** (UEA + HAR + Sleep-EDF, 6 backbones):

```bash
python run_classification.py
```

Classification holds out approximately 20% of each training class for validation
with a fixed split seed of 42. Singleton classes remain in training. If both
`val_inputs.npy` and `val_labels.npy` are supplied, they define the validation
set instead. Early stopping and checkpoint selection use this validation set;
the test set is used only for final evaluation.

The UEA preparation script writes all three splits, fitting normalization,
the label mapping, and sequence length on the training subset. Regenerate UEA
data with `python scripts/data_preparation/UEA/generate_training_data.py` before
running new classification experiments.

**Anomaly detection** (SMD, MSL, SMAP, PSM; 7 backbones):

```bash
python run_anomaly_detection.py
```

**Multi-seed evaluation** (mean / std and paired t-tests):

```bash
python scripts/run_multiseed.py
```

**Dropout-strategy comparison** (original vs. fixed vs. global-learnable vs. SACM):

```bash
python scripts/run_dropout_strategy_comparison.py --dry-run   # preview the matrix
python scripts/run_dropout_strategy_comparison.py
python scripts/run_dropout_strategy_comparison.py --all-horizons --seeds 42,43,44
```

**Selective Learning estimator** (only needed for the `r_a` mask mode):

```bash
python scripts/run_pretrain_estimator.py
```

**Batch-size sweep** (re-runs each setting with different batch sizes while
holding its SACM configuration fixed):

```bash
python scripts/run_batch_size_sweep.py --task forecasting --preset representative \
    --batch-sizes 8 16 32 64 128 --gpus 0 1 2 3
```

### Tables and figures

Paper figures are generated by the scripts in `vis/` (each writes a PDF into
`vis/`). Result tables are aggregated from the per-run metrics written under
`checkpoints/`.
